# 📍 Directorio Interactivo de Locales

¡Bienvenido al **Directorio Interactivo de Locales**! 🗺️  
Una aplicación web que permite explorar, descubrir y conectar con negocios locales a través de **perfiles interactivos y dinámicos**.

## ✨ Características Principales

- 🧭 **Exploración geolocalizada**: Navega por un mapa interactivo o una lista de locales filtrada por categoría, ubicación o nombre.
- 👥 **Perfiles detallados**: Cada local cuenta con un perfil completo con descripción, fotos, horarios, contacto, redes sociales y mucho más.
- 💬 **Interacción en tiempo real**: Posibilidad de chatear con locales (si está habilitado), dejar reseñas o hacer preguntas.
- 🖼️ **Galería multimedia**: Los negocios pueden mostrar imágenes, videos y promociones destacadas.
- 🔍 **Búsqueda inteligente**: Encuentra fácilmente lo que buscas gracias a filtros avanzados y sugerencias automáticas.

## 🚀 Tecnologías Utilizadas

- **Frontend**: HTML5 + CSS3 + Tailwind

- **APIs externas**: Google Maps API
